**Notepad** a simple and minimalistic android app📱 for notes📃
Based on *Room* and *Jetpack Compose* with **Clean Architecture**.

## Tech stack 📚

### 🗃️DI
* **Hilt**

### 💾Data storing
* **Room**
* **Data store**
* **Google Protobuf**

### ⚙️Code generation
* **Ksp**

### 📱UI state
* **Viewmodel**

### 🔧Testing
* **Mockk**
* **Junit**
